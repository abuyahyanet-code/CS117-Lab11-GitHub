# CS-117 Lab 11: Git and GitHub

## Project
Storage Estimator — a Python program that converts file sizes from MB to GB.

## Purpose
This project demonstrates Git version control and GitHub collaboration.

## How to Run
Run the following command in a terminal:

python storage_estimator.py

Enter the file size in MB when prompted.

## Git Skills
- Repository initialization and status checks
- Staging and committing changes
- Inspecting differences
- Branches, Issues, Pull Requests, and merge conflict resolution
